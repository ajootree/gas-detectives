# 기체 단어 퀴즈

초등 4학년 온도·압력과 기체의 부피를 반복하는 단어 카드 선택형 퀴즈입니다.

플레이: https://ajootree.github.io/gas-pang/

- 기존의 24개 상황을 재사용합니다.
- 상황 구분 / 높아짐·낮아짐 / 부피 변화 / 세 단어 연결의 네 가지 연습을 바로 선택합니다.
- 혼자 맞힌 단어는 10점, 오답 복습이나 학습 도움 후 완성한 단어는 5점입니다.
- 오답은 중앙 팝업에 해설과 같은 질문을 제시합니다. 정답을 다시 눌러야 진행합니다. Escape나 틀린 복습 답으로는 넘어가지 않습니다. 복습 상태는 새로고침 후에도 복원합니다.
- 정답을 고르면 짧게 결과를 보여 준 뒤 자동 진행합니다. 시간제한과 점수 차감은 없습니다.
- 온도와 압력의 변화 방향·부피 관계는 온도 네 문제, 압력 네 문제를 먼저 연습한 뒤 섞습니다.
- 키보드 1/2로 카드를 선택할 수 있습니다.

서버·계정·데이터베이스·추적 도구 없이 기기 localStorage의 gas-pang.cards.v1 키에 점수와 진행 상태를 저장합니다. 초기화는 ‘초기화합니다’를 정확히 입력해야 활성화되며 취소하면 유지합니다. 다른 게임·사이트의 저장소는 지우지 않습니다.

이미지와 3D 라이브러리를 사용하지 않는 정적 사이트입니다. 별도 빌드 없이 루트 파일을 GitHub Pages의 main / root로 배포할 수 있습니다. 로컬 실행은 ES 모듈 때문에 HTTP 서버가 필요합니다. 모든 자원 경로는 상대 경로입니다.

검증: 24개 상황의 정답, 점수 계산, 세 단어 연결, 필수 복습 및 Escape 차단, 새로고침 복원, 초기화 입력·취소, 1024×550의 가로 화면에서 페이지 스크롤 없음을 확인했습니다. 실제 태블릿 하드웨어 검사는 별도입니다.
