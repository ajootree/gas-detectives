# 기체 단어 퀴즈

초등 4학년 온도·압력과 기체의 부피를 익히는 단어 카드 퀴즈입니다.

플레이: https://ajootree.github.io/gas-pang/
글꼴 10가지 비교: https://ajootree.github.io/gas-pang/font-samples/

## 학습과 도전

- 기존 24개 상황을 사용합니다. 내부·외부 압력의 구분은 다루지 않습니다.
- 단계: 상황 구분 → 높아짐·낮아짐 → 부피 변화 → 세 단어 연결.
- 처음에는 1단계가 열립니다. 앞 세 단계는 연습과 60초 도전을 선택합니다.
- 60초 종료 시 100점 이상, 첫 응답 기준 정답률 80% 이상이면 다음 단계가 열립니다. 중간 종료는 단계 통과로 인정하지 않습니다.
- 연습은 혼자 맞힌 단어 10점, 해설 복습·학습 도움 후 완성한 단어 5점입니다. 연습 누적 점수와 도전 점수는 별도로 관리합니다.
- 60초 도전은 처음 맞힌 문제 10점, 복습한 문제 0점입니다.
- 연결하기: 연습 / 무한 마라톤 / 120초 도전. 도전은 세 단어를 모두 처음에 맞힌 문장만 30점입니다. 부분 완성·복습한 문장은 0점입니다.
- 마라톤은 첫 오답에 종료됩니다. 오답 해설을 보고 정답을 직접 다시 누른 뒤 결과를 봅니다.
- 모든 오답은 중앙 팝업에서 필수 재응답합니다. Escape로 건너뛰지 못합니다.
- 시간제 도전은 해설 중에도 시간이 흐릅니다. 새로고침·탭 전환 후에도 실제 종료 시각을 유지하고, 정답 처리 직전에도 시간 만료를 검사합니다.
- 1/2 키 또는 터치로 카드를 선택합니다. 도현체를 자체 호스팅하며 OFL 라이선스를 포함합니다. 태블릿 가로 화면을 우선합니다.

## 저장과 랭킹

연습 점수, 열린 단계, 현재 문제·복습, 개인 최고 점수는 localStorage의 `gas-pang.cards.v1`에 저장합니다. 초기화는 “초기화합니다”를 직접 입력해야 활성화됩니다. 취소 시 기록을 유지하며 다른 게임의 저장소와 온라인 랭킹을 지우지 않습니다.

전용 Firebase 프로젝트는 `gas-word-quiz-ajootree`, Firestore Standard `(default)`의 지역은 서울 `asia-northeast3`입니다. 무료 저장소가 생성됐음을 확인했으며 결제 계정·유료 함수는 추가하지 않았습니다. 작은 순위 조회에는 Firestore Lite를 사용합니다.

보이는 회원가입 없이 Firebase 익명 인증을 사용합니다. `gasQuizRuns/{uid}`에 현재 랭킹 도전의 시작을 기록하고, `gasQuizScores/{mode_uid}`에 마라톤·120초 각각 최고 기록 하나만 보관합니다. 자동 생성한 별명, 점수, 모드, 문장 수, 도전 시간 등만 저장하며 이름·이메일·개별 문항 응답을 수집하지 않습니다. 공개 설정 파일의 Firebase 웹 API 키는 클라이언트 식별자이며 관리자 비밀키가 아닙니다.

랭킹은 수동 조회하는 상위 10개 기록입니다. 매 문항 요청과 실시간 구독은 없습니다. 순위 화면과 최종 도전에서만 Firebase 모듈을 불러옵니다. 연결 실패 때는 안내 후 기기 기록으로 시작할 수 있고 연습은 계속 가능합니다.

규칙은 소유자만 제출·갱신, 최고 점수만 갱신, 필드·닉네임 길이·점수 단위·시각·도전 식별자 검증을 적용한 프로토타입입니다. 실제 서비스에서 정상 제출과 잘못된 점수·소유권 변경·제한 없는 조회 등의 거절을 시험합니다. 브라우저의 각 응답을 서버가 검증하지 않으므로 개발 도구로 조작한 점수를 완벽히 방지하는 대회용 방식은 아닙니다. 널리 공유하기 전 실제 이용량과 규칙을 추가 검토할 수 있습니다.

## 배포와 규모

정적 파일은 GitHub Pages의 `main / root`로 배포합니다. 이미지·3D 라이브러리·빌드 과정이 필요하지 않습니다. 기본 실행은 index.html, 두 CSS, JS/MJS, 도현체만 요청합니다. 글꼴 비교 페이지의 10개 글꼴은 게임 시작 시 받지 않습니다. Firebase SDK는 랭킹을 이용할 때 추가 요청합니다.

누적 5천 명 시나리오는 실제 통계나 동시 접속 수가 아닙니다. 일일 이용자·도전 횟수·랭킹 열기 횟수에 따라 Firebase 무료 사용 한도 소진 속도가 달라집니다. 예를 들어 상위 10개가 있는 랭킹을 5천 명이 하루 한 번씩 열면 조회만 약 5만 문서 읽기가 발생하고, 최고 점수 확인·규칙 검증에 필요한 읽기가 추가됩니다. 이 규모가 하루에 집중될 경우 무료 한도에 걸릴 수 있습니다. 무료 한도를 넘겨도 연습과 기기 기록은 계속 사용할 수 있도록 했습니다.

기본 최초 로딩 자원은 압축 전 약 135KiB입니다. 기본 게임과 글꼴 비교·라이선스를 포함한 배포 파일 전체는 약 424KiB입니다. 한 번씩 최초 로딩하는 5천 명을 가정하면 게임 자원은 압축 전 합계 약 0.65GiB입니다. 캐시를 재사용하는 재방문은 줄어들고, 랭킹 SDK·API 응답은 별도입니다. 네트워크 전송량은 압축·브라우저 캐시·CDN 캐시에 따라 달라집니다.

## 관리

Firebase 설정: `.firebaserc`, `firebase.json`, `firebase/`의 규칙·복합 색인. Firebase CLI에 로그인한 환경에서 `npx -y firebase-tools@latest deploy --only firestore,auth --project gas-word-quiz-ajootree`로 재적용할 수 있습니다. 이 명령은 GitHub Pages 프런트엔드를 배포하지 않습니다.

검증 범위: 24개 문항과 정답, 연습 10/5점, 단계 통과·정답률 경계, 중간 종료, 필수 복습·복습 복원, 시간 만료 직전 응답, 연결 완성 점수, 첫 오답 종료, 새로고침 후 시간·진행 유지, 입력식 초기화, 태블릿 화면의 페이지 스크롤 없음. 실제 태블릿 하드웨어 검사는 별도입니다.
