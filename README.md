# 기체 팡! · 새총 탐험대

초등 4학년의 온도·압력과 기체의 부피를 연습하는 정적 웹게임입니다.

게임 주소: https://ajootree.github.io/gas-pang/

## 학습 흐름

1. 상황이 온도와 관련되는지, 압력과 관련되는지 구분합니다.
2. 온도나 압력이 높아지는지, 낮아지는지 판단합니다.
3. 상황 없이 온도·압력과 부피의 네 가지 관계를 반복합니다.
4. 상황을 보고 종류, 변화 방향, 부피 변화를 차례로 연결합니다.
5. 모든 단계를 통과하면 다섯 상황씩 무한 연습합니다.

단계 1은 10상황, 단계 2~4는 12상황 이상 연습하고 최근 10상황 중 8상황을 첫 시도에 도움 없이 완성하면 통과 도전이 열립니다. 온도·압력 유형의 고른 정답 경험도 필요합니다. 단계 2~3은 온도 4문제, 압력 4문제를 먼저 연습한 뒤 섞습니다.

통과 도전은 5상황 중 4상황을 혼자 완성하면 성공합니다. 힌트 사용이나 오답 후 수정은 도움받아 완성으로 기록합니다. 별은 도움받아 완성해도 얻으며, 기존 별·배지는 오답으로 사라지지 않습니다. 조준 정확도와 속도는 통과 조건에 포함하지 않습니다.

문제는 24개 상황을 네 범주로 균등하게 구성했습니다. 따뜻하게·차갑게 하기, 누르기·누르던 힘 줄이기를 중심으로 하며 내부·외부 압력 구분, 법칙 이름, 계산은 출제하지 않습니다. 기체가 새거나 추가되지 않는 조건이며, 온도 문제는 압력이 비슷하고 압력 문제는 온도가 비슷한 조건으로 다룹니다.

## 조작

- 새총 공을 아래로 당겼다가 놓으면 발사합니다.
- 공을 오른쪽 아래로 당기면 왼쪽 표적, 왼쪽 아래로 당기면 오른쪽 표적을 겨눕니다.
- 표적을 터치한 뒤 발사 버튼을 누르는 방법도 제공합니다.
- 키보드: 공에 초점을 두고 좌우 방향키로 선택, Enter 또는 Space로 발사합니다.
- 시간제한은 없습니다. 효과음과 움직임 효과는 설정에서 끌 수 있습니다.
- 기본 화면은 태블릿 가로 방향을 우선합니다. 브라우저 UI를 제외한 1024×650, 1024×550 등의 사용 가능 화면을 기준으로 확인합니다.

## 기록과 개인정보

계정, 서버, 데이터베이스, 분석 추적 도구가 없습니다. 별, 배지, 열린 단계, 학습 기록과 설정은 이 브라우저의 `localStorage`에만 저장합니다. 저장이 막히면 알림을 표시하고 현재 활동은 계속할 수 있습니다.

설정 → 이 게임 기록 초기화에서 `초기화합니다`를 정확하게 입력해야 초기화 버튼이 활성화됩니다. 취소하면 기록을 유지합니다. 삭제 대상은 `gas-pang.slingshot.v1` 키 하나뿐이며 `localStorage.clear()`는 사용하지 않습니다.

## GitHub Pages 배포

별도 빌드나 패키지 설치가 없습니다. `index.html`, `style.css`, `game.js`, `core.mjs`, `icon.svg`, `.nojekyll`을 저장소 루트에 올립니다. Settings → Pages에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다. 모든 자원 주소는 상대 경로라 프로젝트 Pages 주소에서 작동합니다.

로컬 확인 시 ES 모듈을 사용하므로 파일을 더블 클릭하지 말고 정적 HTTP 서버로 실행하세요.

## 규모와 통신량

최종 파일 크기와 검증 기록은 함께 제공하는 `검증기록.txt`를 참고하세요. 실제 이용자 통계가 아닌 누적 5,000회 최초 방문 시나리오로 계산합니다. 동시 접속 수는 가정하지 않습니다.

외부 글꼴·이미지·라이브러리 없이 자체 SVG와 CSS, 브라우저 효과음 합성만 사용합니다. 플레이 중 서버 요청은 없으며 학습 기록을 전송하지 않습니다. 재방문 통신량은 브라우저 캐시와 호스팅의 재검증 동작에 따라 달라집니다.
